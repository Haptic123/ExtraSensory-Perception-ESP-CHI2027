# Database

This page is the entry point for understanding the PostgreSQL database used by the Smartwatch Haptic Feedback system. Use it to find practical researcher guidance, operational backup/restore instructions, and developer-level schema details.

Before making database changes, confirm whether you are connected to a local, staging, or active study database.

Researchers normally should not edit the database directly; ResearcherSideApp and n8n handle database changes.

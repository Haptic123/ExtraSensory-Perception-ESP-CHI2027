# Watch Session Checklist

Use this page during session preparation and quick troubleshooting.

# Quick checklist

- Watch is charged.
- Watch app is installed and running.
- Permissions are granted.
- Watch name matches the expected participant/watch ID.
- Phone can connect to the watch.
- Sensor readings appear when expected.
- Test vibration works if available.

# If readings are missing

Check:

1. The watch app is still running.
2. Body sensor permissions are granted.
3. The phone is connected to the watch.
4. The phone is sending data to n8n.
5. ResearcherSideApp is showing the correct user/use case.

# If vibration does not happen

Check:

1. The active mapping exists for the participant.
2. n8n returns a haptic instruction.
3. The phone receives and relays the instruction.
4. The watch app receives the command and is allowed to vibrate.

# Before changing a workflow

Start with the Researcher guide if you are preparing or running a study. Use the Developer guide when inspecting workflow logic, editing routing, or troubleshooting backend behavior. Use the Experiment Configuration Guides when working with feature-specific settings such as recurring schedules or use-case parameter definitions.

Researchers should usually only touch one workflow: `Vibration Orchestrator`, and only when adding a new use case.

For the full researcher workflow, use the top-level **Adding a New Use Case** page. It connects ResearcherSideApp, the AI assistant chat, and Vibration Orchestrator.

# Dashboard Overview

Use this page to understand what the ResearcherSideApp dashboard is for and what you can do from it.

# What the dashboard helps you do

The ResearcherSideApp is the main place where researchers prepare and manage the study. You use it to choose participants, select use cases, manage haptic feedback mappings, schedule checks, review data, and work with the AI assistant.

# Main areas in the UI

- User selection: choose the participant you are working with.
- Use case selection: choose the study condition or measurement type, such as `HeartRate`, `Pollution`, `AirPressure`, or another configured use case.
- Mappings: view and manage how measured values become haptic feedback patterns.
- Schedules: create and manage recurring checks or scheduled feedback behavior.
- Graphs/data views: review sensor readings and feedback history.
- AI assistant chat: ask for help with mappings, use cases, and workflow guidance.
- Dictionary: describes use-case parameters so the system and assistant have better context.

# When to use the dashboard

Use the dashboard before, during, and after a participant session:

- **Before:** confirm users, devices, use cases, and active mappings.
- **During:** check whether data is arriving.
- **After:** review saved data and note any issues.

# Before a live session

- Confirm the dashboard opens.
- Confirm users load.
- Select the correct participant.
- Confirm the selected participant has the expected use case and mapping.
- Confirm relevant schedules are active or inactive as intended.
- Confirm recent data appears when expected.

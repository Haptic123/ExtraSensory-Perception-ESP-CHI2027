# Watch Setup and Permissions

Use this page before a participant session to confirm the smartwatch app is ready.

# What the watch does

The smartwatch collects participant readings and performs vibration patterns when it receives haptic commands from the phone.

# Requirements

- A Wear OS watch.
- USB or wireless debugging.
- A paired or reachable Android phone for relay testing.

# Required permissions

Grant these permissions when prompted:

- Body Sensors.
- Nearby Devices or Bluetooth.
- Location, if required by the device or study configuration.

# Before you begin

- Confirm the smartwatch app is installed. You can find the app APK below, along with installation instructions:Instructions for installing watch APK [LINK REMOVED FOR ANONYMITY]watch-app.apk [LINK REMOVED FOR ANONYMITY]
- Confirm the app opens.
- Keep the app running for the session.
- Confirm the watch can connect to the Android phone.
- Run one test vibration if possible.

# Watch naming

Use this format:

```
UserID-<ID>-SmartWatchID-<ID>
```

Example:

```
UserID-1-SmartWatchID-1
```

This helps the system connect readings to the correct participant and device.

# Graphs and Data Review

Use this page when you want to inspect readings, trends, or feedback events.

# What the graph/data views are for

The dashboard can show recent or historical sensor data. This helps you check whether the participant-side flow is working and whether the recorded values match the study expectations.

# What to look for

- Are new readings arriving?
- Do the values look plausible?
- Does the selected user match the displayed data?
- Does the selected use case match the displayed data?
- Are feedback events appearing when expected?

# When data is missing

If data is missing, check the system in this order:

1. The selected user and use case in ResearcherSideApp.
2. The Android phone connection to n8n.
3. The Bluetooth connection between phone and watch.
4. The smartwatch app permissions and sensor state.
5. n8n and database status.

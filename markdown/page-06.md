# Phone Setup and Session Checklist

Use this page before a participant session to confirm the Android phone app is ready.

# What the phone does during a session

The phone app connects the smartwatch to the backend. It receives readings from the watch, adds phone-side context when needed, sends the request to n8n, and relays haptic instructions back to the watch.

# Before you begin

- Confirm the smartwatch app is installed. You can find the app APK below. You can download it directly to your phone sotrage and open it.phone-app.apk [LINK REMOVED FOR ANONYMITY]
- Confirm the phone has network access.
- Confirm the phone is configured for the correct n8n/backend environment.
- Confirm Bluetooth is enabled.
- Confirm the phone can connect to the smartwatch.
- Confirm location permissions are available if the use case needs GPS.
- Run a test request if possible.

# During a session

Watch for signs that the phone is still connected to the watch and backend. If readings stop appearing in the dashboard, the phone relay is one of the first places to check.

# Haptic Feedback Documentation

Documentation for the smartwatch haptic feedback system.

- `docs/`: static website, ready for GitHub Pages.
- `markdown/`: sanitized Markdown source pages.

Publish from `main`, folder `/docs`, in Settings → Pages → Deploy from a branch.

This is an anonymous review edition. Identifying links, credentials, media and attachments are omitted. Markdown source edits must also be reflected in the corresponding HTML pages; this package does not include an automatic Markdown build pipeline.
